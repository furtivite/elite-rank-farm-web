# Elite Rank Farm Navigator — сайт

[English](README.md) · **Русский**

Сайт **[Elite Dangerous Rank Farm Navigator](https://frtvt.com/elite)** —
подбирает станции для фарма званий Империи и Федерации: какие станции в
пределах вашего прыжка дают задания нужной фракции, куда лететь дальше с
уже взятыми заданиями и сколько прыжков до каждой цели.

Где вы, на каком корабле и с какими званиями, сайт узнаёт от
**[агента](https://github.com/furtivite/elite-rank-farm-agent)** —
небольшой программы для Windows, которая читает журнал игры, пока вы играете.

## Что здесь есть и чего нет

Этот репозиторий — **фронтенд**: страницы, интерфейс и всё, что считает
браузер, — порядок станций, поиск по снимку галактики, оценка прыжков,
корзина заданий.

Здесь нет:

- **сервера** — API, которое принимает данные агента, учётных записей и
  базы галактики;
- **снимка галактики** — систем, станций и фракций, по которым ищет сайт.
  Его собирает сервер, и он не публикуется.

Поэтому локальная сборка показывает интерфейс, но без сервера нет ни входа,
ни данных командира, ни того, по чему искать: страницы показывают свои
пустые состояния и ошибки.

## Как запустить

Нужен [Node.js](https://nodejs.org) 24.

```text
npm ci
npm run dev
```

Проверки — те же, что в CI:

```text
npm run typecheck
npm run lint
npm run format:check
npm test
npm run build
```

`npm run build` собирает статический сайт в `out/` — Node.js-сервер для
работы не нужен. Чтобы выложить его в подпапку, задайте
`NEXT_PUBLIC_BASE_PATH`, например `NEXT_PUBLIC_BASE_PATH=/elite npm run build`.

## Как устроен код

- **Next.js** (App Router, статический экспорт), **React**, **TypeScript** в
  строгом режиме, **Tailwind CSS**.
- **[Feature-Sliced Design](https://feature-sliced.design)**: слои
  `app → views (pages) → widgets → features → entities → shared`, нижний слой
  не импортирует верхний. Слой страниц называется `views`, чтобы Next.js не
  принял его за Pages Router.
- Интерфейс — **на английском и русском**; тексты лежат в словарях
  `src/shared/lib/i18n`.
- В `contracts/` — JSON-схемы данных, которыми сайт обменивается с агентом и
  сервером; тесты сверяют код с ними.
- Коммиты — по **[Conventional Commits](https://www.conventionalcommits.org)**.
